## Finding S1: definite signed FAIL can become overall VERIFIED

Severity: **P1, release blocking semantic projection inconsistency**. Reachability: ordinary exported `verify(request,bundle)` with admitted, authentic, fully available independent evidence. No monkey patch, forged subprocess output, altered dependency, or direct internal project call is required.

Reproducer: `signed-FAIL-native-VERIFIED.json` contains the exact request, valid signed bundle, complete native inputs, and before-fix report. It is freshly generated by the command above. The fixture differs from the independent positive control only by setting `bundle.statement.asserted_result = 'FAIL'` and producing the corresponding valid Ed25519 signature. The independently observed SHA256 predicate is true; the producer's signed definite assertion is false. The expected product verdict is `CONTRADICTED`, preserving both facts.

Observed before output:

```json
{
  "overall": "VERIFIED",
  "AUTHENTICITY": "VERIFIED",
  "SUBJECT_BINDING": "VERIFIED",
  "RECOMPUTATION": "REPRODUCED",
  "nativeSemanticOutcome": "VERIFIED",
  "reason_codes_include": "ASSERTED_NATIVE_RESULT_CONTRADICTION",
  "EVIDENCE_SUFFICIENCY": "SUFFICIENT",
  "SEMANTIC_COMPATIBILITY": "COMPATIBLE"
}
```

Frozen source cause: `src/core/verify.mjs:90` detects the definite inconsistency, but only appends a reason. `src/projection/project.mjs:8-14` does not treat that reason as a contradiction and accepts the remaining successful layer statuses. `RECOMPUTATION` status has already been normalized to `REPRODUCED` at `verify.mjs:88`. The report simultaneously tells the user VERIFIED and carries a contradiction reason.

This does not prove the requested artifact predicate is false; the replay independently establishes that predicate as true. It proves that the product's overall verdict ignores a detected definite contradiction in authenticated evidence. A repair should preserve replay status and native result while projecting the definite contradiction. A result-code-only patch must also retain the authenticated source assertion in an explainable report.

The reverse direction is covered: a reproduced native REFUTED result stays overall CONTRADICTED. A native positive cannot bypass A/B binding. The issue is the positive replay of an authenticated definite negative assertion.

Native replay identity alone is not a positive semantic result. Extra requested guarantees, continuity or domains add their own exact positive obligations.

The twelve direct project mismatches are **P2 defensive boundary findings** as a group, except the S1 contradiction path above. They are not twelve demonstrated API attacks. They show the internal projection routine assumes a trusted host already validated its inputs.
