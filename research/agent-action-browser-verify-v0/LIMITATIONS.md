# Limits and remaining work

- This is a local, synthetic research integration, not a production verifier or released host profile. One bounded operation is executed and replayed. No claim of arbitrary agent semantics, truthful model judgment, training-data quality, external execution or real-world agent identity is established.
- The signed-action adapter verifies supplied laboratory observations. `OBSERVATION_SUPPLIED` is preserved; it is not remote service evidence. Existing public test keys are intentionally reproducible and provide no real-world authority.
- Log inclusion and signatures are checked, but public-log authenticity, independently selected trust roots, external publication, freshness, non-equivocation, CT consistency and claim authorization are `NOT_COVERED`. Full-manifest extension is finite set retention, not an append-only transparency protocol.
- Canonical interoperability holds only within `agent-action.receiptos-common-json.v0`. Historical receipt roots, source observations and release artifacts are unchanged. The current lens pin adds CC0 metadata with identical selected runtime bytes. Existing root conventions differ outside the admitted domain. Permissively parsed objects cannot preserve evidence of duplicate raw keys.
- Native verdicts are retained. The product projection is explicitly versioned and limited to this profile; it is not a universal translation of upstream status enums. A failure can leave later dimensions `NOT_CHECKED`.
- The browser independently recomputes receipt bytes, while local host checks remain trusted local computation. This is not a standalone offline static page with all verification in the browser, and not a remote-attested verifier. No external network requests occurred in the recorded browser test, which does not prove universal sandbox isolation.
- The original research run executed 417 relevant inherited tests plus 13 contract checks, with separate fixture, canonical, browser and mutation runs. [Cold-review repairs](COLD_REVIEW_REPAIRS.md) preserve those populations and subsequent counts. The final inventory/license integration separately reran the full current production suite sequentially: 707/707, with no skips. This does not broaden the action profile to QEV/RNG/PQ/provider claims; its selected CI host/profile lane remains a distinct test population.
- Mutation controls are finite. The report lists witnesses, changed cases, unexpected changes, positive controls and restoration. Every possible malformed branch, upstream implementation and cryptographic primitive is not mutation-complete. A no-op is `NOT_COVERED`; a syntax crash is `CRASHED`; neither is a kill.
- Cold review found seven previously unnamed guards and three missing outside-receipt witnesses. Three receipt-root-protected checks remain independently unwitnessed. Supplemental kills do not establish exhaustive guard or conjunct coverage; see the separate original/supplemental populations in [the repair record](COLD_REVIEW_REPAIRS.md).
- The current global source inventory now includes research, nested locks and the workflow under the explicit [v2 policy](../../docs/source-inventory-policy.md). Original v1 inventory/checker bytes remain as pinned snapshots. Exactly two current metadata paths are versioned; the other 2,154 baseline files, including historical receipts/reports, remain byte-identical. Current global closure, bounded research closure and historical preservation remain separate gates; passing them is file-identity evidence, not semantic correctness.
- The current recompute-lens pin `61f7392f1c4758231517b22ba06ab608dedbae02` carries its official upstream CC0-1.0 license; its selected runtime bytes are unchanged from the historical pin. Earlier receipts and license observations remain historical. It is still an external local dependency: this integration pass adds no distribution packaging or vendored third-party source, modifies no upstream branch, and makes no claim of sole authorship over reused components.
- Three named earlier reports were not found in the searched local locations. Some unrelated C: dependency directories were inaccessible to the filename search. Memory Palace and current source were used; absent report contents were not invented.
